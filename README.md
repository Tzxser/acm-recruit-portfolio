# ACM 协会招新网站

面向高校 ACM 算法与竞赛协会的招新展示网站，使用 Next.js、React、TypeScript、Tailwind CSS 与动画组件。展示算法学习路径、竞赛信息、技能图谱与招新交互。

## 建议阅读

- 页面组织：`app/page.tsx`。
- 算法可视化：`components/algorithm-graph.tsx`、`components/algorithm-arena.tsx`。
- 竞赛信息结构：`lib/competitions.ts`、`lib/certifications.ts`。
- 交互与响应式界面：`components/`、`app/globals.css`。

## 开发

安装相应 Node.js 与 pnpm 后运行 `pnpm install --frozen-lockfile`、`pnpm dev`。项目以 v0 生成的 Next.js 基础开始迭代，依赖与版本见 `package.json`。

## 展示范围

此副本用于展示前端实现，真实群号、二维码及活动照片已替换为展示占位内容。页面中的赛事时间属于原页面内容快照，不作为当前报名通知。公开副本未重新进行完整构建与上线验收。
